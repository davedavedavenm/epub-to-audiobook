Setup & Configuration

Welcome to Audiobook Studio! These settings help you connect your studio to other services. None of these are strictly required to start converting books, but they unlock powerful extra features like automatic syncing to your library and faster processing.

Render Location

Local is the default and is free. Free Kaggle can be selected per book. Paid Vast provisioning cannot be enabled from this unauthenticated web app; it requires an explicitly approved host-admin session, and queue length never triggers it.

Free Cloud GPU — Kaggle

Render any book on a free Kaggle GPU (much faster than your own machine) by choosing Render on → Kaggle GPU when you start a book. You get ~30 free GPU-hours a week. Your token is stored securely on this server and never leaves it.

How to get your token (2 minutes, free): 1) Sign up at kaggle.com and verify your phone (Settings → Phone Verification — required for GPU internet). 2) Go to kaggle.com → your avatar → Settings → API → Create New Token. 3) Open the downloaded kaggle.json and copy the username and key below.

Audiobookshelf Sync

Automatically send finished audiobooks directly to your Audiobookshelf server. Find your token inside Audiobookshelf by clicking your username (top right) -> Settings -> Users -> select your user -> API Token.

LLM Integration (Optional)

Connect an OpenAI-compatible LLM (e.g., Z AI, xAI, Groq, OpenAI) for optional metadata generation and chapter-structure classification. Automated pronunciation guesses are disabled by default because they have damaged narration; structural audio checks do not use this cloud setting.

Gemini 3.1 Audiobook Voice — Free Tier Only

Achernar passed the long-form listening gate. The app supports all 30 official Gemini preset voices, but exposes a Play-ready audition only after that exact preset has been generated and cached. It uses only the Gemini Developer API Free Tier: no Vertex endpoint, no batch billing, no automatic retry and no paid fallback. Create a dedicated AI Studio project whose Plan says Free, do not attach Cloud Billing, then add GEMINI_API_KEY, GEMINI_FREE_PROJECT_ID, GEMINI_FREE_PROJECT_CONFIRMED=1 and ENABLE_GEMINI_PROFILE=1 to the host .env and redeploy. Quota exhaustion pauses the book; completed passages resume from disk.

Pronunciation Dictionary (All Books)

Regex rules applied to every conversion, one per line as search==replace. Lines starting with # are comments. Per-book rules live in each book's "Advanced" panel in the Library.

Amazon Polly Voices (Legacy — not recommended)

⚠️ Proven too expensive for full audiobooks (see LOW-COST-TTS.md); kept only for compatibility. Audition the target book and use only a voice that passes its quality sample. Piper is retained only for legacy comparison and is not a production fallback. You must have an AWS account with 'polly:SynthesizeSpeech' permissions.

Inworld TTS 1.5 — Premium Voices (Optional)

Expressive paid engine. Pay-as-you-go: ~£2–£5 per novel — ⚠️ at or above the project's £3/book budget rule (LOW-COST-TTS.md), so treat as premium/experimental only. Get your API key at inworld.ai →

Deepgram Cloud TTS (Aura-2)

High-speed cloud neural TTS powered by Deepgram. Aura-2 models (Orion, Orpheus, Arcas, Pandora, Hyperion) deliver expressive, natural narration at \$0.030 per 1,000 characters. Enter your API key from console.deepgram.com.

Vast.ai Cloud GPU Speedup (Optional)

Legacy manual Vast.ai access. Saving a key or adding books to the queue will never rent a GPU. Paid provisioning is a separate, explicit session action; free local or Kaggle rendering should be used wherever possible.
