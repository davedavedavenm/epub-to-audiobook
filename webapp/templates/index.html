Setup & Configuration

Welcome to Audiobook Studio! These settings help you connect your studio to other services. None of these are strictly required to start converting books, but they unlock powerful extra features like automatic syncing to your library and faster processing.

Render Location

Where audiobooks are generated. Local is the default and is free. Cloud GPU rents a paid Vast.ai instance (a few pence per book, but it bills by the hour until destroyed). Only switch to Cloud GPU when you deliberately want to spend credit for speed.

Free Cloud GPU — Kaggle

Render any book on a free Kaggle GPU (much faster than your own machine) by choosing Render on → Kaggle GPU when you start a book. You get ~30 free GPU-hours a week. Your token is stored securely on this server and never leaves it.

How to get your token (2 minutes, free): 1) Sign up at kaggle.com and verify your phone (Settings → Phone Verification — required for GPU internet). 2) Go to kaggle.com → your avatar → Settings → API → Create New Token. 3) Open the downloaded kaggle.json and copy the username and key below.

Audiobookshelf Sync

Automatically send finished audiobooks directly to your Audiobookshelf server. Find your token inside Audiobookshelf by clicking your username (top right) -> Settings -> Users -> select your user -> API Token.

LLM Integration (Optional)

Connect an OpenAI-compatible LLM (e.g., Z AI, xAI, Groq, OpenAI) to unlock advanced features like automated metadata generation (summaries/titles), custom pronunciation lexicons for tricky names, and quality assurance transcript checks.

Pronunciation Dictionary (All Books)

Regex rules applied to every conversion, one per line as search==replace. Lines starting with # are comments. Per-book rules live in each book's "Advanced" panel in the Library.

Amazon Polly Voices (Legacy — not recommended)

⚠️ Proven too expensive for full audiobooks (see LOW-COST-TTS.md); kept only for compatibility. The studio's free voices (Kokoro, EdgeTTS, Piper) are the recommended path. You must have an AWS account with 'polly:SynthesizeSpeech' permissions.

Inworld TTS 1.5 — Premium Voices (Optional)

Expressive paid engine. Pay-as-you-go: ~£2–£5 per novel — ⚠️ at or above the project's £3/book budget rule (LOW-COST-TTS.md), so treat as premium/experimental only. Get your API key at inworld.ai →

Vast.ai Cloud GPU Speedup (Optional)

When you add multiple books to the queue, it can take a long time to process on your local machine. If you provide a Vast.ai API key, the studio will automatically rent a cloud GPU for a few cents an hour to process the books ~15x faster, and then automatically shut it down when finished.
